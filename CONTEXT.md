# Roam Kumaon Context

## Glossary

### Booking
A chauffeur-driven vehicle service starting from a **Pickup Point** and ending at a **Drop-off Point**.

### Quote Request
A formal inquiry from a user for the pricing of a **Booking**. Includes details like pickup/drop-off, date, passengers, and preferred vehicle category. In Phase 1, these result in a **Manual Quote** delivered via external communication (e.g., WhatsApp/Email).

### Manual Quote
A price estimate provided by the operator after reviewing a **Quote Request**, rather than being calculated automatically by the system.

### Vehicle Category
The classification of the vehicle required for the service (e.g., Sedan, SUV).

### Pickup Point
The starting location of a **Booking**. (Phase 1: Kathgodam, Haldwani)

### Drop-off Point
The destination location of a **Booking**. (Phase 1: Nainital, Bageshwar)

### Rental
A self-drive vehicle service where the customer drives the vehicle themselves. In Phase 1, this is restricted to **2-wheelers** (Bikes/Scooters).

### Rental Location
A location where a **Rental** can be initiated and returned. (Phase 1: Kathgodam)

### Rental Duration
The period between the **Start Date** and **Return Date** for a **Rental**, used to calculate the quote.

### Rental Rate
The daily charge for a **Rental**. In Phase 1, this is provided via a **Manual Quote** (indicative rate: ₹1000/day, excluding fuel).
